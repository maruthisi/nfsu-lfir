# nfsu-lfir — Ansible

Inventory (`inventory/hosts.yml`) is generated by OpenTofu on every `terraform apply`
and emptied by `destroy.sh`. Two playbooks:

- `drop_files.yml` — deploys the file-drop sender onto the sources (cron'd scp to all
  mirrors at random 3-4 min intervals for a 15-min window, then self-stops), and preps
  `/var/data` on the mirrors.
- `setup_nginx_mirror.yml` — OPTIONAL. nginx is already installed at boot (cloud-init)
  on every VM, serving `/var/data`. Use this playbook only to reconfigure nginx.

## Run (from iac/ansible/)

```bash
# 0. Confirm connectivity
ansible -i inventory/hosts.yml all -m ping

# 1. Start the drops from the sources (nginx is already up from boot)
ansible-playbook -i inventory/hosts.yml playbooks/drop_files.yml
```

Then open `http://<mirror-ip>/` — the dropped `malicious_test.txt` appears within a
few minutes and every 3-4 min after, until the 15-minute window closes.

## Timing / payload knobs

Edit the `vars:` in `playbooks/drop_files.yml` (`drop_min_interval`, `drop_max_interval`,
`drop_duration`, `drop_dest_dir`, `drop_filename`) or the payload in `files/malicious_test.txt`.
